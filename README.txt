Как получить APK:
1) Создай репозиторий на github.com и загрузи в него ВСЁ содержимое этой папки (включая скрытую папку .github).
2) Открой вкладку Actions -> Build APK -> дождись зелёной галочки (2-4 минуты).
3) Открой запуск -> Artifacts -> moj-grafik-smen-apk -> скачай zip, внутри app-debug.apk.
4) Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

Альтернатива: открыть папку в Android Studio и выбрать Build -> Build APK(s).
